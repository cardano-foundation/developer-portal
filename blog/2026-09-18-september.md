In this session of the Cardano Developer Office Hours, Giovanni Gargiulo, Senior Blockchain Architect at the Cardano Foundation, presents cardano-dev-skills, an open-source initiative designed to equip AI coding agents with accurate, up-to-date Cardano knowledge. He explores how domain-specific agent skills support Aiken smart contracts, transaction building, CIP lookups, and chain queries, and how vetted documentation helps reduce outdated or inaccurate AI-generated code. The session also covers integration with tools such as Claude Code and Hermes, and how developers can contribute new skills to the ecosystem.
