# Quick Start: your first end-to-end dApp

The fastest way to feel how Cardano development fits together is to build one small, complete dApp. Here you'll build an **Atomic Swap**: `soon`

You will move through the whole loop — on-chain validator, off-chain transaction building, and a frontend — so nothing stays abstract.

## Steps

1. **Tools + high-level overview** — what a dApp, smart contract, Aiken, and MeshJS are.
2. **Set up your environment** — scaffold the project and connect a browser wallet.
3. **On-chain: Atomic Swap** — the on-chain validator.
4. **Off-chain: Atomic Swap** — build and submit the transaction.
5. **Integrate with a frontend** — wire it into a UI.
