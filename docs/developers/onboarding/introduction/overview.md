# Welcome to Cardano

Cardano is a public blockchain: a network of computers, run by many independent people, that keep one shared record of who owns what. Anyone can read that record, and anyone can change it by sending a transaction that follows the rules. Some of those rules are programs called smart contracts. Once a smart contract is on the chain, nobody can get around its rules, not even the person who wrote it.

With that, you can build apps where people pay, trade and agree on things directly, with no company in the middle holding the money or the keys.

## What this onboarding is

This onboarding takes you from your first Cardano project to a smart contract that is ready for mainnet. It is written for developers who already build software, for the web for example, and have never worked with a blockchain. Every Cardano term is explained where it first appears.

It is hands-on. Each page ends with something you run and see for yourself, on a test network where the coins have no value. The code on the pages is imported from example projects that are tested automatically, so the code you read is the code that runs.

It does not choose your tools for you. Cardano has several languages for smart contracts and several libraries for the code that builds transactions. Where the code depends on the tool, the page shows it in tabs, one per tool, and more tabs will be added. **[Builder Tools](/tools)** lists what is available.

## What it covers

1. **[Get started](/docs/developers/onboarding/get-started/overview)**: create a new Cardano project with one command, by hand or with an AI coding agent.
2. **[What to build](/docs/developers/onboarding/what-to-build/overview)**: what people build on Cardano today, who builds it, and the spaces nobody has filled yet.
3. **[Tutorial](/docs/developers/onboarding/tutorial/overview)**: one small app you download and run, an atomic swap where two people trade tokens without trusting each other. It walks you through the contract, the code that builds the transactions, and a page in the browser.
4. **[Lectures](/docs/developers/onboarding/lectures/introduction)**: a guided path in three modules. **Beginner** explains wallets, UTxOs, transactions and tokens. **Intermediate** teaches you to write, test and use smart contracts. **Advanced** makes them secure and cheap to run, teaches the design patterns production protocols are built from, and takes a contract to production.

## Where to start

To see the whole picture first, run the **[Tutorial](/docs/developers/onboarding/tutorial/overview)**. It shows every part of a Cardano app working together, and the lectures then explain each part in depth.

To learn step by step, start the **[Beginner](/docs/developers/onboarding/lectures/beginner/introduction)** module and take the lectures in order.

If you already know what you want to build, **[Get started](/docs/developers/onboarding/get-started/overview)** creates the project, and the lectures are there when you need them.
