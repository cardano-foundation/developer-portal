# Archived blog social cards

Retired social cards for 37 blog posts, kept out of the way rather than deleted.

These were not designed cards. Each one is a browser screenshot of the blog post
as the portal looked at the time, so they carry the pre-2026 chrome: the teal
announcement bar, the white navbar, a "Showcase" nav item that no longer exists,
and the "Recent posts" sidebar. Sharing any of those posts advertised a version
of the site that is no longer live.

Blog cards are now generated at build time by `scripts/generate-og.js`, the same
way docs cards are, so every post gets a current, on-brand card and no image
files need committing. Nothing here is referenced by the site.
